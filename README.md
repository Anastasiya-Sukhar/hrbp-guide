# HR BP: роль и влияние на бизнес

Интерактивный одностраничный методический гид по функции HR Business Partner в РТК ИТ — для руководителей. Все тексты вынесены в `data.json`, персональные данные и внутренние цифры обезличены.

## Файлы

| Файл | Назначение |
|---|---|
| `index.html` + `styles.css` + `app.js` + `data.json` | Развёрнутая версия (тексты отдельно — удобно редактировать) |
| `hrbp-standalone.html` | Автономная версия: весь сайт в одном файле |
| `build.py` | Пересборка автономной версии после правок: `python build.py` |

## Как опубликовать на GitHub Pages

1. Зайдите на [github.com/new](https://github.com/new) и создайте **публичный** репозиторий, например `hrbp-guide`.
2. На странице репозитория нажмите **Add file → Upload files**.
3. Если нужен только рабочий сайт — перетащите **один файл** `hrbp-standalone.html` и переименуйте его в `index.html` (кнопка с карандашом рядом с именем файла).
   Если хотите редактировать тексты отдельно — загрузите все четыре файла: `index.html`, `styles.css`, `app.js`, `data.json`.
4. Нажмите **Commit changes**.
5. Откройте **Settings → Pages** (левое меню, раздел Code and automation).
6. В **Source** выберите **Deploy from a branch**, ветка `main`, папка `/ (root)` → **Save**.
7. Через 1–2 минуты сайт будет доступен по адресу:

```
https://<ваш-логин-github>.github.io/hrbp-guide/
```

Ссылка появится там же на странице Settings → Pages — её можно отправлять кому угодно.

## Проверка перед публикацией

Откройте `hrbp-standalone.html` двойным кликом — автономная версия работает и без сервера.

## Редактирование

Все заголовки, карточки, квиз и уровни зрелости лежат в `data.json`. После правок запустите `python build.py`, чтобы пересобрать автономную версию.
